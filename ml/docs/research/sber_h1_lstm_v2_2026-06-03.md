# SBER H1 — LSTM Sequence Model v2 — 2026-06-03

## Hypothesis

ExtraTrees видит плоский снимок 27 чисел в момент t. Даже с явными лаговыми фичами
(эксперимент sber_lag_sequence, Δ=−0.003) ExtraTrees не научился паттернам последовательности.
LSTM через hidden state накапливает память по 32-шаговому окну и должен улавливать
паттерны вида "3 часа вниз + рост объёма = разворот".

Ключевое исправление v2 vs v1: добавлены time-фичи (hour_sin/cos, dow_sin/cos) в каждый
шаг последовательности. v1 без них обрушился на fold 4 (0.396) — модель не понимала
контекст времени суток, который несёт 62% важности у ExtraTrees.

---

## Архитектура

```
Input: (batch, 32, 14)
  — 32-шаговое окно (32 часа ≈ 4.5 торговых дня)
  — 14 фич на шаг: ret_1h, ret_3h, body, range_, upper_shadow, lower_shadow,
    close_pos, vol_ratio, vol_z, hour_sin, hour_cos, dow_sin, dow_cos, ema_dist

LSTM(input=14, hidden=128, layers=2, dropout=0.3, batch_first=True)
  → берём h_n[-1] (hidden state последнего слоя на последнем шаге)

Head: Linear(128→64) → ReLU → Dropout(0.3) → Linear(64→3)

Loss:   CrossEntropyLoss (без class weights на v2)
Optim:  Adam(lr=0.001, weight_decay=1e-4) + CosineAnnealingLR(T_max=50)
Stop:   early stopping patience=8 на val macro-F1
Batch:  256, max epochs=50
```

Walk-forward: 4 expanding фолда, initial_train=12000, val=2000.
Семена: [7, 42, 100]. Тест-сплит не тронут.

## Ключевые наблюдения

### 1. Time-фичи критичны для любой модели
v1 без time-фич: fold 4 = 0.396. v2 с ними: fold 4 = 0.440 (+4.4%).
LSTM самостоятельно учится паттернам времени суток точно так же, как ExtraTrees.
**Вывод: hour_sin/cos/dow_sin/cos обязательны в input для всех моделей.**

### 2. LSTM превосходит ET на средних фолдах
- Fold 2: 0.494 vs 0.488 (+0.006)
- Fold 3: 0.495 vs 0.477 (+0.018)

Fold 3 — наиболее впечатляющий: +1.8% прироста. LSTM лучше обобщается когда
накопил больше обучающих данных (15 968 последовательностей).

### 3. SELL F1 значительно улучшился
SELL: 0.4461 vs ET 0.4204 (+0.026). LSTM лучше идентифицирует нисходящие движения —
вероятно, потому что медвежьи паттерны (несколько красных свечей подряд + рост объёма)
хорошо читаются в 32-шаговом окне.

### 4. BUY F1 пока слабее ET
BUY: 0.4085 vs ET 0.4195 (−0.011). Бычьи паттерны сложнее — часто выглядят как
случайный отскок, а не как начало движения. Нужно больше обучающих данных или
более длинный контекст.

### 5. Fold 4 — режимный сдвиг 2025-2026
Оба метода деградируют на fold 4 (последний год данных). Причина: возможная смена
рыночного режима (геополитика, структурные изменения MOEX, изменение ликвидности).
Это ограничение данных, не архитектуры.

### 6. Обучение быстрое (10-24 эпохи до early stop)
Модель не переобучается — она просто не видит достаточно паттернов. Это сигнал, что
нужен либо более богатый input, либо более длинное окно.

## Предложения по следующим шагам

### Приоритет 1 — Изменить горизонт таргета: h=3 → h=6 (ожидаемый прирост: +0.05..0.08)

**Почему это самый важный шаг:**
Triple-barrier с h=3 на часовых данных — очень зашумленный таргет. За 3 часа цена
успевает пройти барьер и вернуться обратно, что порождает ложные лейблы. При h=6
(6 часов ≈ целая торговая сессия) паттерн либо подтвердился, либо нет — сигнал чище.

```python
# Изменить в эксперименте:
TARGET_SPEC = ActionTargetSpec(
    mode="triple_barrier", barrier_horizon=6,  # было 3
    barrier_vol_window=12, barrier_up_k=1.25, barrier_down_k=1.25,
)
```

Скрипт: `ml/scripts/sber_target_horizon_research.py`
Время: ~2 часа (нужно перебрать h=3,4,6,8,12 на обоих моделях).

### Приоритет 2 — Гибридная модель: LSTM hidden state + ExtraTrees прогнозы (ожидаемый прирост: +0.01..0.03)

LSTM силён на паттернах последовательностей (SELL), ET силён на структурных фичах
(time-based, volatility). Их можно объединить:

```
LSTM(seq) → 128-dim hidden state ─┐
                                   → concat(256-dim) → Linear(3) → softmax
ET(snapshot) → 3-dim probabilities ─┘
```

Или проще: взвешенное среднее их вероятностей (ensemble).
Скрипт: `ml/scripts/sber_hybrid_research.py`
Время: ~1 день.

---

### Приоритет 3 — Transformer вместо LSTM (ожидаемый прирост: +0.02..0.05)

В 2026 году Transformers с self-attention доминируют в sequence modeling. Ключевое
преимущество для нашей задачи: attention может выбирать КАКИЕ шаги из 32 важны
(например, конкретные часы с аномальным объёмом), а LSTM обрабатывает равномерно.

Простая архитектура (уже реализуемо на PyTorch):
```python
# TransformerEncoder: 2 слоя, 4 головы, d_model=64
encoder_layer = nn.TransformerEncoderLayer(d_model=64, nhead=4, dim_feedforward=128, dropout=0.1)
transformer = nn.TransformerEncoder(encoder_layer, num_layers=2)
# + Linear projection 14→64 на входе, pooling по времени, Linear 64→3 на выходе
```
Скрипт: `ml/scripts/sber_transformer_research.py`
Время: ~1 день.
