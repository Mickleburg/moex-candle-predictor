# H9 no-lookahead — часть B — 2026-06-17

**Вопрос:** дивидендный run-up слив входит на оффсете −12 ТД до record date. Стратегия легитимна,
только если дивиденд (размер + дата) ПУБЛИЧЕН до входа. Иначе — lookahead.

**Статус: НЕ-LOOKAHEAD ХОРОШО ОБОСНОВАН (институционально + data-driven). Финальная пер-событийная
проверка ждёт дат объявления из e-disclosure (LLM-чат).**

## 1. Институциональный аргумент (закон)
По ФЗ-208 «Об АО» ст. 42:
- Record date («дата составления списка лиц») устанавливается ОСА; record = ОСА + 10..20 дней.
- Уведомление об ОСА (несёт РЕКОМЕНДАЦИЮ СД по дивиденду — собственно информационное событие)
  публикуется ≥21 день до ОСА.
- ⇒ дивиденд становится публичным на **рекомендации СД, за ~22-38 ТОРГОВЫХ дней до record date** —
  задолго до нашего входа на −12. К моменту входа размер и (ориентировочно) дата известны.

## 2. Data-driven проверка (без дат объявления) — ПРОЙДЕНА
Если бы объявление попадало ВНУТРЬ окна входа [−15,−2], оно дало бы ЦЕНОВОЙ СКАЧОК (всплеск среднего
abnormal return в этот день). Проверка (`ml/scripts/h9_nolookahead_check.py`, 120 событий):
- AAR внутри окна [−15,−3]: гладкий дрейф, max |AAR| = **0.0036**.
- Ex-гэп на −1: **0.0224** — в **6.2×** больше любого внутри-оконного дня.
- Крупнейший одиночный внутри-оконный день = **26%** от всего run-up (нет доминирующего скачка).
- ⇒ **гладкий дрейф, скачка-объявления внутри окна НЕТ** → информация существует ДО окна входа.
  Согласуется с no-lookahead.

## 3. Что осталось — ФИНАЛЬНАЯ проверка (нужен LLM-чат)
Строго: для каждого события (ticker, record_date) нужна **дата первого публичного объявления**
дивиденда (дата рекомендации СД / публикации существенного факта на e-disclosure). Тест:
`announce_date ≤ entry_date` (entry ≈ record_date − 12 ТД ≈ −17 календарных дней) для всех событий.
Если выполняется для ~всех — no-lookahead подтверждён окончательно.
Промпт для LLM-чата: `ml/docs/LLM_CHAT_PROMPT_dividend_announce_2026-06-17.md`.
Источник данных: e-disclosure.ru (существенные факты «о решениях СД», «о проведении ОСА»,
«о решениях ОСА»), либо IR-страницы эмитентов.

## Вывод
No-lookahead для H9 run-up — обоснован двумя независимыми линиями (закон + отсутствие скачка в окне).
Это снимает основной риск артефакта. Полная сертификация — после дат объявления от LLM-чата
(дешёвый join + один булев тест). Слив остаётся `is_production=false` до этого + forward-shadow.
