# Кросс-секционный оценочный риг + ценовой бенчмарк (H2/H3) — 2026-06-15

## Зачем
H1a показал: цена сама по себе не даёт маркет-нейтральной альфы. Чтобы честно проверить
тезис «новости добавляют сигнал», нужен ОДИН фиксированный риг, оценивающий любую фичу/модель
одинаково — иначе «новости бьют цену» несравнимо. Этот риг — `ml/scripts/xsec_eval_harness.py`.

## Что меряет
- **Rank IC (Spearman)** — на каждую дату решения корреляция кросс-секционного СКОРА бумаги с её
  реализованной ОТНОСИТЕЛЬНОЙ forward-доходностью (доходность − средняя по вселенной). Стандартный
  диагностик кросс-секционной альфы: стабильно положительный IC ⇒ скор ранжирует бумаги. Дёшево
  считается для кандидата-новостной фичи ЕЩЁ ДО полного бэктеста.
- **Маркет-нейтральный бэктест** — long top-k / short bottom-k, неперекрывающийся ребаланс каждые H
  дней, комиссия; in-sample (<2025) vs forward (≥2025).

## Ценовой бенчмарк (моментум) — планка, которую новости должны побить

| Фича | H | forward IC (IR) | bt forward нетто | win |
|------|---|-----------------|------------------|-----|
| mom_L20 | 20 | **+0.063 (0.20)** | **+0.134** | 0.52 |
| mom_L20 | 10 | +0.055 (0.17) | −0.098 | 0.50 |
| mom_L10 | 20 | +0.053 (0.17) | +0.101 | 0.59 |
| mom_L60 | 10 | +0.047 (0.13) | −0.019 | 0.50 |

Везде IC крошечный (0.01–0.06), IR 0.1–0.2, in-sample ≈0. У цены лишь маргинальная
кросс-секционная предсказуемость. **Планка низкая → пространство для новостной фичи есть.**

## Интерфейс для новостного чата (как подключить фичи)

Новостная фича подключается как **score-функция**: `(daily_panel, t) -> np.ndarray` (по одному
скору на тикер вселенной), используя ТОЛЬКО данные на момент t (no-lookahead; для новостей —
`sources[].published_at <= t`, инвариант №3). Пример (после получения llm_analysis фич):

```python
from ml.scripts.xsec_eval_harness import load_daily_panel, evaluate_scores, UNIVERSE

def news_score(panel, t):
    date = panel.index[t]
    # для каждой бумаги вселенной взять последние новостные фичи с published_at <= date
    # пример скор: sentiment * impact_score (потом — выход решающей модели)
    return np.array([news_feature(tkr, date) for tkr in panel.columns])

m = evaluate_scores(load_daily_panel(), news_score, horizon=20, k=3, label="news_sent")
# Критерий ценности: m['ic_fwd_mean'] > ~0.05 со стабильным IR>0 И m['bt_fwd_cum'] > 0.
```

**Критерий «новости полезны» (H2):** forward rank IC новостной score_fn устойчиво > ценового
бенчмарка (~0.05) с IR>0 и положительным forward-бэктестом нетто. **H3 (ранняя фьюжн):** решающая
модель на `[цена ⊕ новости]` бьёт по forward IC любую модальность по отдельности.
