# SBER H1 -- LSTM Sequence Model -- 2026-06-03

## Hypothesis
LSTM with 32-step OHLCV sequences models temporal dependencies that ExtraTrees
cannot learn even with explicit lag features. The hidden state accumulates
pattern memory across the 32-hour window.

## Architecture
- Input: (batch, 32, 9) — 9-dim scale-invariant features per timestep
- LSTM(128, layers=2, dropout=0.3)
- Head: Linear(128->64) -> ReLU -> Dropout(0.3) -> Linear(64->3)
- Loss: CrossEntropyLoss | Optim: Adam(lr=0.001) + CosineAnnealingLR
- Early stopping: patience=8 on val macro-F1
- Batch: 256 | Max epochs: 50

## Input features (9 per timestep)
- ret_1h, ret_3h: price momentum
- body, range_, upper_shadow, lower_shadow: candle shape
- close_pos: close position within candle range
- vol_ratio, vol_z: volume anomaly detection

## Results

| Model | F1 mean+-std | Worst fold | SELL | HOLD | BUY | Delta vs ET baseline |
|-------|-------------|------------|------|------|-----|---------------------|
| ExtraTrees baseline | 0.4738+-0.0217 | 0.4377 | 0.4204 | 0.5815 | 0.4195 | -- |
| LSTM (32-step) | 0.4591+-0.0371 | 0.3955 | 0.4419 | 0.5459 | 0.3896 | -0.0147 |

## Conclusion

LSTM did not outperform ExtraTrees (delta=-0.0147).
Possible reasons: MOEX 1H triple-barrier target has high noise at 3h horizon;
LSTM may be underfitting on CPU with small batch. Consider:
  - Longer horizon target (h=6 or h=12)
  - Larger architecture or attention
  - Pre-training on unsupervised next-candle prediction
  - Longer sequence (SEQ_LEN=64)
