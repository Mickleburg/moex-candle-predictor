# ML Docs

Документация внутри `ml/docs/` относится к Python ML research/inference блоку.

Сначала см. [итоговые исследовательские результаты](../../docs/RESEARCH_RESULTS.md) и
[индекс решающих проверок](research/README.md). Датированные ранние отчёты сохраняют промежуточные
выводы, впоследствии пересмотренные: финальный V1-гейт и H9-forward не пройдены.

- `research/` - отчеты по SBER H1, candle-language, target redesign, triple-barrier и action features.

Корневой `docs/` используется для общей технической документации проекта, не привязанной только к ML research.
