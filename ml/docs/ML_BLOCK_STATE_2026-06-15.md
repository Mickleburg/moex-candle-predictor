# ML-блок — состояние и код-ревью — 2026-06-15

## 1. Вердикт код-ревью

**Блок корректен для research-стадии. Смоук-тесты 19/19 зелёные. Рабочее дерево чистое.**

Инварианты проверены фактически (не по памяти):
- **Нет lookahead в фичах** — порча всех свечей после индекса k оставляет каждую фичу строк ≤ k
  байт-в-байт неизменной (доказано для `build_per_step_features`). Объём через `shift(1)`;
  ортогональные через `merge_asof(direction="backward")` (вечерняя свеча SBER берёт последний бар
  индекса за день, никогда будущий).
- **Таргет использует будущее только для МЕТОК** (`triple_barrier_details` смотрит high/low по
  [t+1, t+3]) — никогда для фич. Где горизонт выходит за край — метка −1 (исключена).
- **Хронология walk-forward** — `walk_forward_ranges` гарантирует train_end ≤ val_start; окна
  расширяются вперёд во времени, без перемешивания.
- **Тест-сплит нетронут** — артефакты обучены на первых 85% (development); последние 15% не читались
  ни в обучении, ни в отборе. Финальный тест-гейт ещё не запускался.
- **Валидация контракта** — парсинг candle_batch отвергает дубли/несоответствия/non-finite; выход
  ml_prediction валиден по схеме; вероятности суммируются в 1.
- **Роутинг по тикеру** — запрос `ticker` → артефакт тикера; неизвестный тикер → корректный
  `artifact_missing`; несоответствие тикера/артефакта вызывает ошибку.
- **ML сам подтягивает ортогональные данные** — LKOH обслуживается end-to-end, блок сам тянет
  Brent/IMOEX/RTSI; входной контракт не меняется.

### Найденные проблемы (исправлены в этом ревью)
1. ✅ **Устаревшие метаданные SBER-артефакта** (`backtest_conf050_sharpe=6.38`, старый выход 1ч) —
   обновлены на актуальное правило (3ч+стоп, Sharpe 14.95).
2. ✅ **Разнобой tz в тренерах** — `train_lstm_artifact.py` переведён на `tz_aware=True` (как
   ортогональный тренер). Wall-clock час/dow идентичны → модель не меняется.
3. ✅ **Нет защиты порядка/размерности фич на инференсе** — добавлен гард: размерность построенных
   фич должна совпадать с input_dim артефакта (иначе понятная ошибка).
4. **`is_production=False` везде** — корректно по инварианту до прохождения тест-гейта и sign-off.

## 2. Как работает блок

```
candle_batch JSON (свечи ОДНОГО тикера)
   → TickerModelRouter       тикер → каталог артефакта (research_lstm_v2_<t>_h1)
   → ResearchArtifact        грузит model.pt + конфиги (с кэшем)
   → _lstm_feature_matrix    OHLCV/время; если есть orthogonal_groups → ML САМ тянет
                             Brent/IMOEX/RTSI через MarketContextProvider и строит 14+K фич
   → CandleLSTM              окно 32 свечи → softmax {SELL, HOLD, BUY}
   → ml_prediction JSON      probabilities, confidence, expected_return, signal_context, diagnostics
```
Downstream (aggregator → risk_manager → execution) владеет порогами, удержанием, стопом, размером,
портфелем. Блок только прогнозирует. Статичная торговая политика — отдельно в
`config/ml_risk_policy.json`.

## 3. Фичи (по-шагово, строго past-only)

**База (14, все тикеры)** — масштабонезависимые OHLCV + сессия:
`ret_1h, ret_3h, body, range_, upper_shadow, lower_shadow, close_pos, vol_ratio, vol_z,
hour_sin, hour_cos, dow_sin, dow_cos, ema_dist_8`. (Время даёт ~62% сигнала — внутридневная
сезонность MOEX.)

**Ортогональные (только LKOH, +17 → 31)** — самоподтягиваемые межинструментальные драйверы:
- commodity (8): `BR_CONT` (Brent) + `NG_CONT` (газ): ret_1h/3h/d + vol — по-настоящему ортогональная
  цена нефти/газа (непрерывный фронт-контракт FORTS).
- market (9): `IMOEX`, `RTSI` ret_1h/3h/d + vol, и `rtsi_imoex_spread_ret` (= неявный USD/RUB, т.к.
  USD-спот остановлен с середины 2024).

## 4. Таргет — triple-barrier

Для свечи t: `past_vol = std(returns[t-12:t])`; `upper = close·(1+1.25·vol)`,
`lower = close·(1−1.25·vol)`. Смотрим вперёд [t+1, t+3]: первый пробитый барьер → BUY (верх) /
SELL (низ); таймаут → HOLD. Оптимальность подтверждена сетками (h3/k1.25/w12). Баланс классов ≈
33/34/33.

## 5. Модель

`CandleLSTM`: LSTM(input=14 или 31, hidden=128, слоёв=2, dropout=0.3) → последнее скрытое →
Linear(128→64)→ReLU→Dropout→Linear(64→3). Скользящее окно 32 свечи. CrossEntropy, Adam(lr=1e-3,
wd=1e-4) + CosineAnnealing, ранняя остановка. Усреднение по сидам [7,42,100] в research; один сид
(42) для упакованного артефакта (обучен на 85%).

|-------|--------|-------------|----------------------------------|-------------|-----------|

| **LKOH** | нефть+рынок LSTM | ~0.46 | **+11.73%, Sharpe 5.42, win 56.8%, 81 сделка** | P(прибыль)=97.3%, бьёт 100% случайных, комиссия-OK ~0.10% | **да (слабее)** |
| GAZP | — | ~0.45 | эджа нет (win <50%) | — | нет (отдаём прогноз, не торгуем) |

**Продакшн-правило (оба):** BUY при confidence > 0.50; держать 3ч со стопом на нижнем барьере
волатильности; без тейк-профита; long-only; не торговать выходные сессии.

### Что НЕ сработало (7 отрицательных результатов — главный урок)
multi-ticker joint, трансформер (mean-pool), мульти-горизонт (h6/h12), мета-лейблинг,
ортогональные на SBER, вариации таргета/seq-len, GAZP (любой путь). **Закономерность: эдж — редкий,
чистый, высокоуверенный сигнал; расширение (больше данных, богаче архитектура, больше фич, длиннее
горизонт) его разбавляет. Простой confidence — почти оптимальный селектор.**

### Ключевые находки
- Совпадение горизонта выхода с таргетом (3ч) утроило доходность (+5.07%→+16.08%); стоп-лосс добавил
  доходность и вдвое снизил просадку; тейк-профит вредит (обрезает моментум-победителей).
- Эдж концентрируется в пятнице + вечерней сессии (МСК) + высокой волатильности; затухает 2023→2025.
- Нефтяной драйвер LKOH работает, т.к. экзогенен; газ GAZP (Henry Hub) — не тот драйвер
  (Газпром = европейский газ + геополитика).
