## Ликаге — чисто
- Нет forward-лукахеда в сервинге. Все `shift(-)` — конструкция таргета/лейбла в research-коде
  (закрытые линии) или time-shuffle КОНТРОЛЬ. H9-слив использует record-ДАТЫ (анонс заранее,
  no-lookahead сертифицирован) + прошлые vol.
- `is_production=true` встречается ТОЛЬКО в тестах (гипотетический подписанный слив) и докстрингах.
- Тест-сплит не используется для тюнинга. `except Exception` — везде документированные tolerant-фолбэки.
