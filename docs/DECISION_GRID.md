# Decision grid — контракт сетки между ML и LLM/news блоками

Источник правды: `ml/src/features/decision_grid.py` (материализуется в
`data/features/decision_grid.csv`). Новостной слой обязан выдавать фичи РОВНО на этих
`(ticker, as_of)` точках, иначе работа и LLM-квота тратятся впустую.

## Решение (владелец — ML-блок, 2026-06-16)

| Параметр | Значение |
|----------|----------|
| **Каденс** | **DAILY** — одно решение на торговый день (1708 as_of, 2020-01..2026-06) |
| Вселенная | 12 ликвидных бумаг (`cross_sectional.UNIVERSE`) → 20 496 `(ticker, as_of)` ячеек |
| `as_of` | закрытие торгового дня (MSK). Новость пригодна ⟺ `published_at <= as_of` |
| Новостное окно | trailing 7 календарных дней до `as_of`, агрегат по тикеру (разрежённые дни несут недавнее окно) |
| Таргет/холд | forward относит. доходность (`beta_residual`) на H∈{5,10,20} торговых дней, **перекрывающиеся портфели** |
| Комиссии | не страдают: решаем ежедневно, держим H дней → дневной оборот ~1/H |
| No-lookahead | фичи в `as_of` — только цена `<= as_of` и новости `published_at <= as_of` |

**Почему дневной (а не недельный):** тоньше ловит импакт новости в дни после раскрытия (неделя
размывает), больше обучающих точек. Стоимость LLM (~20k ячеек, ~11ч @ RPM30) принята —
считается оффлайн с кэшем. Недельный (4020 ячеек) — дешёвый fallback, если квота прижмёт:
`decision_grid(cadence="weekly")`.

## Порядок (дисциплина проекта: не платить до доказанного эджа)

1. **Baseline-новостной слой** (детерминированный, бесплатный, мгновенный) на сетке → собрать
   `feature_bundle` [цена ⊕ новости-baseline] → прогнать **H2 deployment-симуляцией** (цена vs
   цена+новости). Это разблокирует весь конвейер без LLM-квоты.
2. **LLM-слой** — только если baseline что-то даёт (или для честного H3 early-vs-late). Лениво,
   кэш, троттлинг, на ТОЙ ЖЕ сетке.

## Интерфейс кода

```python
from src.features.decision_grid import load_grid          # as_of точки
from src.features.feature_bundle import assemble_feature_bundle  # [цена ⊕ новости] -> контракт

# news: tidy-таблица [ticker, as_of (tz-aware), sentiment, impact_score, ...]
bundle = assemble_feature_bundle(panel, news, as_of)        # валиден по feature_bundle.schema.json
```

Новостная таблица от LLM-блока: колонки `ticker, as_of, <news_cols>` (по умолчанию
`sentiment, impact_score`; расширяемо). Сборщик делает no-lookahead-джойн на цену.
